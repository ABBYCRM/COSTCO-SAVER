# COSTCO-SAVER

> **Warehouse price intelligence network — scan, verify, save.**

COSTCO-SAVER lets a Costco shopper stand in front of a product, scan its
barcode, and learn whether the displayed price is a clearance markdown,
how fresh the price is, what it cost recently, and whether another nearby
warehouse is cheaper. The app grows more accurate as more shoppers
contribute verified shelf observations, receipt imports, and price
confirmations.

## Product promise

> **Scan it before you buy it.**

Every scan yields a current verified price, a markdown classification, a
freshness signal, evidence, confidence, price history, nearby-warehouse
comparison, savings percentage, and (where applicable) a price-adjustment
opportunity.

## Architecture

The product is intentionally **not** built on a generative AI model. Every
domain decision — barcode normalization, price-code classification,
confidence, consensus, freshness, deal score, adjustment detection,
warehouse health — is implemented in deterministic TypeScript and
SQL functions.

```
┌─────────────────────┐
│ Native barcode scan │ Capacitor (iOS + Android)
└──────────┬──────────┘
           ▼
┌─────────────────────┐
│ Product identity    │ product_identifiers (UPC / EAN / GTIN / Costco item #)
└──────────┬──────────┘
           ▼
┌─────────────────────┐
│ Price observations  │ price_observations (shelf_scan | receipt | confirmation | correction)
└──────────┬──────────┘
           ▼
┌─────────────────────┐
│ Confidence engine   │ 0..100 deterministic
└──────────┬──────────┘
           ▼
┌─────────────────────┐
│ Consensus engine    │ groups by price, weights by evidence × recency × submitter
└──────────┬──────────┘
           ▼
┌─────────────────────┐
│ Warehouse price state│ derived table — read by every product detail screen
└──────────┬──────────┘
           ▼
 Deals · History · Watches · Adjustments · Trip Mode
```

## Deploy

### Mobile (iOS / Android)

Codemagic, configured in `codemagic.yaml`. The required workflows are:
`verify`, `android-internal`, `ios-testflight`, `release-candidate`,
`production`. Apple and Google credentials are stored in Codemagic secret
groups (`costco_saver_apple`, `costco_saver_google`).

### Web (DigitalOcean App Platform)

The web bundle is served from `dist/`. To deploy, the operator runs:

```
export DO_API_TOKEN="dop_v1_..."
export GH_TOKEN="ghp_..."
./scripts/deploy-do.sh
```

The script reads `do-app-spec.yaml`, creates the DO App, and polls until
the first deployment reaches a terminal state.
